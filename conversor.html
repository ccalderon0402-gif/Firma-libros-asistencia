Instrucciones de publicación
1
Descarga trabajadores.json con este conversor.
2
Sube a tu repositorio GitHub estos archivos:
index.html  ·  trabajadores.json  ·  firma_dia.png  ·  firma_noche.png
3
Activa GitHub Pages en Settings → Pages → Source: main branch / root.
4
Comparte el link público con los trabajadores. Ellos solo ven el buscador por RUT.
5
Cuando cambie la dotación: repite el proceso y reemplaza solo el trabajadores.json en GitHub.
